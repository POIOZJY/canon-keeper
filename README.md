# Canon Keeper 动态长期设定

一个面向 SillyTavern 的前端扩展：把你在文本框中维护的长期世界设定注入每次生成，并在正文完全生成后，使用当前连接的 API 静默检查长期变化。

## 主要功能

- 每次生成时使用双层约束：完整设定进入主提示区，聊天深度 0 再加入简短的最终一致性检查。
- 将设定统一视为约束集合，要求模型在每轮生成前找出全部相关约束，并检查明示内容、合理暗示和必要省略是否一致。
- 正文完成后才进行后台检查，不把检查结果显示在聊天中。
- 只接受精确、最小的原文替换；程序会拒绝大范围改写。
- 区分长期设定与情绪、衣着、动作、天气等临时状态。
- 严格受限的长期事实新增：每轮最多一条、三项评分均不低于 0.9、独立限额和重复检查。
- 每项自动变化绑定其来源 AI 回复。删除、编辑或切换该回复后，会按仍然存在的消息重新计算并自动回滚。
- 设定和变更账本保存在当前聊天的 metadata 中，不同聊天互不污染。
- 支持实际注入内容预览、token 占用显示、每轮后台原始结果、历史查看、重查最后回复以及 JSON 导入导出。
- Chat Completion API 优先请求结构化 JSON；不支持时自动回落到兼容解析模式。

## 安装

1. 打开 SillyTavern 的“扩展”面板。
2. 选择“安装扩展”，填入：

   ```text
   https://github.com/POIOZJY/canon-keeper
   ```

3. 安装完成后刷新页面。
4. 打开一个角色聊天，在扩展设置中找到“Canon Keeper 动态长期设定”。
5. 粘贴设定并点击“保存为新基准”。

## 数据与回滚模型

自动变化不会覆盖初始基准，而是作为事务保存：

```text
基准文本 + 当前聊天中仍然存在的来源事务 = 当前有效设定
```

因此，删除造成某项变化的 AI 回复后，该事务不再参与计算，设定随即恢复。Git 历史和导出的 JSON 备份也可以用于恢复。

## 重要限制

- 扩展可以保证设定被加入请求，但任何提示词都无法保证模型百分之百遵守。
- 后台判断质量取决于当前连接的模型。格式错误、内容不确定或程序校验不通过时，本轮不会修改。
- 手动点击“保存为新基准”会把文本框当前内容确立为新基准，并清空之前的自动事务。
- 当前版本把全部有效设定注入每次请求；设定过长会占用上下文。界面会按当前接口读取对应的酒馆上下文上限，显示计算分母，并在超过约 30% 时警告。
